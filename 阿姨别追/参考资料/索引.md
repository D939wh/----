# 参考资料 · 索引（教学版代码，不参与游戏运行）

> 这里的文件都是**教学副本**：从正式代码简化而来，讲解「为什么这么设计、怎么改」。
> 改坏了不影响游戏。**游戏代码里只留中性功能注释，「为什么」类讲解都搬到了这里。**

| 文件 | 教什么 | 对应的正式代码 |
| --- | --- | --- |
| 参考答案_状态机.gd | 一坨 if 怎么拆成「一个行为一个文件」；抢占优先级表；怎么加新行为模式（四步） | `组件/状态机/`、`角色/学生/student.gd` 的 `抢占()`、`角色/学生/状态/` |
| 参考答案_读条.gd | 通用读条「条只画不数秒」；三行用法；能借不建、用完必收；三个踩过的坑 | `界面/读条/读条.gd` |
| 参考答案_物件代理.gd | 编号账本；一次按键的旅程；清单生成 vs 手动拖（**手摆必须填 thing_id**）；怎么加新东西 | `单例/场景总管.gd`、`场景/物件代理/物件代理.gd`、`数据/` |
| 参考答案_场景架构.gd | 总管 + 代理 + 门「谁跟谁说话」的总原理（写于楼层代理时代，思路仍适用，名字以物件代理版为准） | `单例/`、`场景/`、`交互物/门/` |
| 参考答案_负重.gd | 扛多重算几档、每档罚什么；为什么改手感去改表不改代码 | `数据/重量档位.gd`、可搬运箱子、钥匙板 |
| 参考答案_抛投.gd | 按住 F 蓄力、松手扔出去：抛物线组件（45° 反解初速 + 逐小步探地探墙）、档位换算身位、被扔的人怎么落地、调手感动哪三个数 | `组件/抛投/抛投.gd`、`角色/学生/student.gd` 的蓄力一段 |
| 参考答案_student.gd | 学生脚本的整体讲解（**停在 2026-11-04 的旧版**：旧层号 + 拆状态机前的单文件写法，之后的新功能不在里面，行数对不上时以正式 student.gd 为准） | `角色/学生/` |

**怎么挑着看**：

- 想加一个新的学生行为（躲柜子、装死）→ 看状态机
- 想加一个新的长按动作（撬锁、包扎）→ 看读条
- 想加一种新的地图物件（灯、快递柜）→ 看物件代理
- 想调「扔多远、蓄多满、弧度多飘」，或想知道被扔出去的人怎么落地 → 看抛投
- 手动拖进场景的东西按 F 没反应 → 直接看物件代理第四段
