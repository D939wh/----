# 阿姨别追 · 长期记忆（跨会话）

## 主人定的硬口径（容易搞反的，先看这里）

- **手机端**（2026-11-05 21:55 原话）：「手机端要放缓做，要到最后做，只是我们开发的时候不考虑。因为由我来考虑，我做框架的时候我都会给我们留后路的。」
  → **不是「不做」，也不是「按手机预算算」**。是**排到最后做、开发期完全不考虑**：分辨率 / 地图尺寸 / 实例数量 / 美术规格全按电脑定，不为手机让路、不提前降配。后路由主人自己在框架里铺，AI 不许按手机预算砍设计，也不许拆已留的后路。像「死物进图块、活物才建节点」照样做，但理由是**维护成本**，不是手机。
- **框架不许 AI 设计**：「框架是不可能交给你想的。你会搞得非常麻烦，像一团面条。」要动框架先问主人。
- **新求生者必须是实例**：只能摆 `student.tscn` 的实例，**不许复制文件**；改了学生，所有实例一起变。
- **门 / 锁口 / 钥匙板 / 出口都是场景数据节点**：位置与参数走 `数据/楼层清单.gd`，不许写死在脚本里。
- **凡是要长按的事，都要有读条**：通用组件 `界面/读条/`，别再画第二根。分工是「谁长按谁数秒，条只画」。
- **12 秒 / 读条期间人要被钉住**：站定不能动是设计要求，不是 bug。
