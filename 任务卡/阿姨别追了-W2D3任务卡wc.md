## 三、今天做四件（按这个顺序）

### 第 1 件 · 电闸箱能被"照清单长出来"

**为什么先做这个**：电闸箱要是手摆进场景，合闸的事就散成了"这一个箱子"；它得跟门一样从清单里长出来，将来加第 3 座、第 5 座才只是改一行字。

**做什么**——完全照门的三步，一步不多：

| 步 | 门怎么做的 | 电闸箱照抄 |
|---|---|---|
| 数据 | `楼层清单.gd` 里 `"门": [ ... ]` | 同一个楼层的字典里加 `"电闸箱": [ ... ]`，每座写编号 + 位置 |
| 建出来 | 代理 `_ready` 照清单循环、调 `门.setup(楼层, 编号, 位置, 用时)` | 同一段循环旁边再加一段，调 `电闸箱.setup(楼层, 编号, 位置, 读条秒数)` |
| 认得出来 | 感应区在 `door` 组 | 感应区在 **`breaker`** 组 |

**新目录**：`交互物/电闸箱/`（和 `交互物/门/` 平级），里面 `电闸箱.tscn` + `电闸箱.gd`。顺手在 `project.godot` 的 `folder_colors` 加一条颜色，跟门那个蓝色一套。

**节点结构**（跟门一样四样，多一个钥匙贴图）：

| 节点 | 干什么 |
|---|---|
| 根（Node2D） | 站哪儿，坐标由清单给 |
| 贴图（占位色块） | 箱子长什么样 |

### 第 2 件 · 按 R 插钥匙 → 锁死 → 读条 12 秒 → 计数

**为什么 12 秒而不是短一点**：这是策划案原文（§3.3 / §6 表），我不改数字。等宿管会追人时再谈要不要降到 8 秒。

**学生这边只加"读键 + 往上报"，不判断碰到的是什么**：

```
按 R → Director.report(楼层, "interact", {谁=我, 键="insert_key", 碰到=[感应区里的东西]})
      → 代理认：这是电闸箱 → 调 箱子.插钥匙(谁)
```

**电闸箱自己管自己**（跟门管使用权一个道理，代理不管进度）：

- `插钥匙(谁)`：没人插过才接受；插上 → 钥匙贴图显示、告诉那个角色"你被锁住了"
- `_process` 里涨进度，12 秒到 → 报一次"我合上了"
- 中途被打断（今天没人打断，逻辑先留着）：进度保留，钥匙留在箱上

**锁死怎么做**：学生身上新加一个开关（比如 `锁住`），在 `_physics_process` **最前面**跟"瘫痪 / 被扛"那三个判断并排——真锁死，走不了跳不了爬不了。**不做"走出范围就暂停"那套**，因为人根本走不开，写了就是死代码。

**为什么必须动旧文件**：读键只能写在角色身上（你定的"按键写在玩家节点里"），建箱子只能写在代理身上。所以这次**不是纯新增**，我上一轮说"只新增不改旧"这句，在这里做不到，先纠正。

**要碰的旧文件就三处，每处都是加分支、不改原逻辑**：

| 文件 | 加什么 | 原有逻辑动没动 |
|---|---|---|
| `角色/学生/student.gd` | 读 R、加 `锁住` 开关、瘫痪时读 H | 不动，只在开头多一个判断 |
| `场景/楼层代理/楼层代理.gd` | 建电闸箱、认 `insert_key`、记合闸数 | 不动，`match` 里多一个分支 |
| `数据/楼层清单.gd` | 加 `"电闸箱"` 段 | 门的段一个字不动 |

**你验收**：F5，扛着钥匙板站到箱前按 R → 钥匙出现在箱上、手里没了、人动不了 → 12 秒后打印"合闸 1/2"。中途按 A/D **完全没反应**。

### 第 3 件 · 合满 2 座 → 两扇门全开

**为什么放今天**：不通到门，电闸箱就只是个会打印的装饰。演示要看见"合完了，门真的开了"。

**做什么**：代理记着一个数（合了几座 / 共几座）。到 2 座 → 让这一层两扇门直接变全开。

**门这边要加一个入口**（`被断电()` 之类），因为现在只有 `press(谁)` 一条路，而断电不是"推"出来的。这是**第二处碰旧文件**，只加一个新函数，`press()` 和抢使用权那套一行不动。

**你验收**：F5，合满 2 座 → 走出两步，两扇门都是开着的、能穿过去。

### 第 4 件 · 按 H 自救（**这件可砍**）

**为什么今天做**：你说的"单机没人来救，先给个自救"。它和读条是同一个零件，一起做省事。

**规则（我给的默认，改哪条说哪条）**：

- 只在**瘫痪**状态下按 H 才有效，站着按 H 什么都不发生
- 按下 → 读条 **2 秒** → 调现成的 `拉起()`（补满血、解除瘫痪）
- 读条中途不挨打就能起来；中途再被打 → 取消（今天没宿管，这条先挂着）

**要碰的旧文件**：`student.gd` 的瘫痪分支（现在瘫痪了直接 `return`，什么键都不吃，得在它前面留一条 H 的路）。**这是第三处、也是风险最高的一处**——瘫痪和打人是刚验收过的，改完必须把打人那十一项回归跑一遍。

**你验收**：F1 切宿管把自己打到瘫痪 → F1 切回来 → 按 H → 2 秒后站起来、血量回到 2 格。
