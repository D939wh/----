## 四、技术方案候选（两个，推荐 A）

### A. 地板留在图块里，靠「第二个物理层」做单向（推荐）

TileSet 支持多个物理层。现在只有一个 `physics_layer_0`（`collision_layer = 1`，墙和地都在这）。
再加一层 `physics_layer_1`，`collision_layer = 16`，只给**地板图块**挂**单向**碰撞多边形；
墙仍然只挂第 1 层。

- 站着：角色 mask 含第 1 层 + 第 16 层，踩得住
- 按 S：只关第 16 层，墙还挡人，不会钻墙
- 美术：地板照旧用图块画 → **逻辑与渲染天然分离**

代价：地板图块要和墙图块分开（图块 ID 不同），画地图时注意别拿错砖。

### B. 地板做成独立节点，由清单生成（原型走的就是这条）

`薄地板.tscn` + 清单里写 `{起, 止, y}`，代理照单建一条 StaticBody2D。

- 优点：地板位置是数据，改坐标不用重画图
- 缺点：**地板是死物，按策划 §7.6.1 该进图块，建节点是例外**；
  而且这个节点一旦自己画一条线（原型就这么干了），逻辑和渲染就粘在一起了

### 对比

| | A 图块单向 | B 独立节点 |
| --- | --- | --- |
| 符合「死物进图块」 | ✅ | ❌（要写例外理由） |
| 逻辑/渲染分离 | ✅ 天生分离 | ⚠️ 要人为克制不画东西 |
| 改地板坐标 | 要重画图块 | 改一个数字 |
| 加一层楼 | 画一层图块 | 清单加一行 + 代理节点 |
| 和现有梯子/门的做法一致 | 梯子将来也要进图块（W2D4 计划） | 门是管理器型，地板不是 |

**推荐 A**，理由是它和「梯子进图块」是同一个方向，也不用为地板开一个架构例外。
除非主人更看重「地板坐标能当数据改」——那选 B，但必须遵守第五节的隔离规矩。

## 五、逻辑层 / 渲染层必须分开（本轮重点）

原型最大的毛病：`薄地板.gd` 里带了一个 `显形` 开关，一开就自己 `Polygon2D` 画一条线。
**物理组件里长出了美术。** 这必须拆掉，不是风格问题，是会互相拖累：

- 美术要换颜色/加贴图 → 得改物理脚本
- 物理要调厚度/单向 → 会动到画出来的东西
- 关掉显形，美术就丢了；打开显形，正式地图里就多出一条不该有的线

### 四层分工（写死，谁越界谁错）

| 层 | 只干一件事 | 文件/节点 | 不许干 |
| --- | --- | --- | --- |
| 数据 L0 | 写位置、层号、段号 | `数据/楼层清单.gd`、`数据/物理层.gd` | 不写判断、不许有 if |
| 物理 | 提供碰撞（单向、厚 8px） | 图块物理层（方案 A）/ StaticBody2D（方案 B） | 不画任何东西、不认识「层」这个概念 |
| 逻辑 | 按键判定、判层、防呆 | `student.gd` + `Director.floor_of()` | 不碰颜色、不建美术节点 |
| 渲染 | 画地板、画墙、光照 | TileMapLayer / 美术资源 | 不决定能不能穿、不知道 S 键 |

**三条硬规矩：**

1. **物理组件里不许出现 `Polygon2D` / `Sprite2D` / `ColorRect`。** 要看得见就交给渲染层。
2. **地板层号只写一份。** 新建 `数据/物理层.gd`，`const 地板层号 := 5`，其他文件全部引用它。
   原型把 `5` 在 `薄地板.gd` 和 `student.gd` 各写了一遍——这就是门秒数那个坑的翻版。
3. **物理层要有登记处。** 现在实际占用：1=世界/墙、2=瘫倒的人、3=梯子感应区、4=拾取感应区。
   新加第 5 层（值 16）必须先登记进 `物理层.gd`，不然下一个人迟早撞车。

## 六、判层：不能只看 y

原型里 `Director.floor_of()` 是按「脚下最近的那条地面线」算的（y 越小越高）。
**只要每层是一条完整水平带，这就够用。** 但类银河城一旦出现：

- 竖井（一个洞上下贯通好几层）
- 同一高度左右两段互不相连（左边是 3F、右边其实是 2F 的上方）

按 y 一条线判就会错：人在左边 3F 掉进竖井，落到右边 2F 的地面，
总管会以为他还在 3F，交互递给错的代理。

**所以判层的最小单位是「层 + 段」**，清单建议长这样：

```gdscript
"层段": [
    { "楼层": "2F", "段": "A", "地面y": 300.0, "x起": 0.0, "x止": 900.0 },
    { "楼层": "2F", "段": "B", "地面y": 300.0, "x起": 1200.0, "x止": 2100.0 },
]
```

判定：先用 y 找到候选段，再用 x 确认在不在段里；不在任何段里 = 正在空中（报「空中」，
不要硬塞给某一层）。
