3. **发声点最小集**（每件交互物在自己发生变化的那一刻 emit 一句，别集中写）：

## 二、B · 阿姨靠声音寻敌，和现在的结合（主人编号 ①）

### 现状（11-09 刚落地的第一档）

`角色/宿管/宿管.gd` 已套状态机，四个状态：`手控 / 待机 / 巡逻 / 追击`。
`抢占()`（L156-168）优先级：**手控 > 察觉圈里有人 → 追击 > 待机/巡逻**；`decide()`（L193-196）只有「看见 → 追击 / 看不见 → 巡逻」。
`追击.gd` 吃的是**目标 Node**（追 `_看得见的目标()` 返回的实体），贴身 30px 站住（这轮不做打人）。
框架 §10.2 记着：没听觉、没搜索、没视野锥、没 0.4 秒过渡；状态表里的「察觉 / 搜索 / 归位」都是 ⏳。

### 关键：声音给的是「坐标」，不是「敌人」

现有追击是一条「看见某个实体 → 朝它走」的链。声音只能告诉她**刚才哪儿响了**，看不见那个人。所以不能把声音塞进 `追击.gd`，得补一个新状态：

- 新建 `角色/宿管/状态/搜索.gd`：朝「最后已知位置」走，到了附近绕一小圈（框架 §10.2 目标形态 3.6 秒），**这期间看见了人就交回追击，一直没看见就回巡逻**。
- 转向加 ≥0.4 秒过渡（框架 §10.2 硬要求，禁止瞬移式转向）。

### 改动边界（照框架 §10.2 写死的规矩，别越界）

**只许动这五处，其余一个字不改：**

| 文件 | 加什么 |
|---|---|
| `角色/宿管/状态/状态名.gd` | 加一行 `const 搜索 := "搜索"` |
| `角色/宿管/宿管.gd` | `_搭状态机()` 加一行 `加()`；`抢占()` 加一行；`decide()` 加一个分支；新增服务函数 `听见声响(位置, 半径, 来源)`、`_最后声响位置`、`_最后声响时刻` |
| `角色/宿管/状态/搜索.gd` | **新建** |

**不许动** `待机/巡逻/追击` 三个状态文件，**不许回 `宿管.gd` 的 `_physics_process` 里塞 if**。这是上一轮拆状态机刚立的规矩，破一次就白拆了。

### 优先级与保底

```
手控（F1 玩家在操作她）  >  看见人（追击）  >  听见声（搜索）  >  待机 / 巡逻
```

- **手控最高不能动**：宿管AI自测里「手控吃键位仍走 108px」那条回归基线全靠它。玩家操作她时，声音只记录、不抢状态。
- 声音过期（默认 3 秒）或走到位置仍没看见人 → 回巡逻，不许原地钉死。
- 框架 §10.2 的目标优先级「扛钥匙板 > 扛其他重物 > 最近声响」这轮**不做**，等打人那轮一起做；明天只按「看见 > 听见」两档。
- **「只记方向不记距离」是给 HUD 表现层说的**，逻辑层必须记声源坐标才能走过去搜索——别照字面把位置丢掉。
- 墙体遮挡：第一档先做纯半径 + 可选一条射线（物理层 1 地板/墙）；完整视野锥/遮挡采样不在这轮。

### 验收（明天要能演出来）

1. 学生站在察觉圈 **外**（>360px）开门 / 插钥匙 → 宿管掉头朝声源走，走到附近没找到人再回巡逻；
2. 同一时刻「看得见的人」和「更近的声响」都在 → **优先追看见的人**；
3. 声音超过有效期后不再驱动她；
4. F1 切到宿管，走/跳/爬梯/开门/挥击/抓捕手感和今天一字不差；

### 3.2 新规则（先说人话）

**门被三块钥匙板真正解锁后，哪个学生自己走到门外站稳 1 秒，就记谁赢；游戏不结束，其他人接着跑。一个人都没跑出去，就什么都不结算、也不判输。**

> 和旧卡的关键区别：不是「全队赢」，也不是「第一个出去就冻结全场」。每个跑出去的人各拿各的胜利，出口和账本要能连着判第二、第三个人。

五条缺一不可：

| # | 条件 | 判法 |
|---|---|---|
| ① | 门必须是「解锁」开，不是「推开」开 | 账本只认新的 `door_unlocked`；`door_finished` 继续存在，但胜负不认它 |
| ② | 出门的必须是学生 | 学生加进 `student` 组；宿管在 `keeper` 组，天然排除 |
| ③ | 必须活着、站着 | 沿用「有 `拉起` 方法 + `not 瘫痪`」；被扛着的人碰撞体是关的，进不了判定区 |
| ④ | 必须自己走进去，不是被扔进去 | 进区域那一刻 `在飞()` 为真 → 这次不算；要离开区域后、再自己走进来才重新计时 |
| ⑤ | 必须站到门外侧 | 现在出口和门是同一个坐标（清单里都是 968,464），分不出内外。**读条只在人位于门线外侧时推进**，退回门内就清零 |

> ⑤ 需要知道哪边是楼外：给清单里的出口加一个「出门方向」（+1 = 右 / -1 = 左），默认 **+1**。判定区不用挪，只要「在门外侧」才计时。门厅外面到底在左还是右，见 3.5 ②。

### 3.3 谁说了算、判完干什么

1. **新建唯一账本** `单例/对局数据.gd`，挂载名必须英文 **`Match`**（autoload 用中文名会被引擎按 Latin-1 解成乱码，事件中枢 §5.6 踩过）。`project.godot` 里排在 `Director` 之后、`Events` 之前（框架 §5.6：前面的不能依赖后面的）。

   **不建 `phase` / `result` / `match_ended`**：这轮不结束对局、不判输，建了也是没人用的死字段。
2. **把「门开了」拆成两件事**：`门.gd` L80 弹开时，`door_finished` 照发（门的表现在不变），再加一句 `Match.door_unlocked(编号)`；L92 推开 / 关上只发 `door_finished`，不通知账本。出口删掉 L44 那条连接，改连 `Match.door_unlocked` 并核对编号。

4. **账本按人去重**：同一个学生只记一次；追加进 `escaped` → 发 `door_escaped(谁)`。**不暂停、不冻结全场。**

### 3.4 验收（要能演出来，不是「跑一下没报错」）

1. 一块钥匙不插，按 E 推开门、站门口 1 秒：**不算赢**，账本 `escaped` 还是空。
2. 三块插满 → 门弹开 → A 自己走到门外站 1 秒：A 记一次赢；**游戏不冻结**，B 还能动、宿管还能追。
3. A 逃出后：按方向键 / F1 对 A 没反应、A 不挡路；B 照常玩。
4. B 也走到门外站 1 秒：B 也记一次赢，`escaped.size() == 2`；同一个人不会被记第二次。
5. **两个人都不出去**：从头到尾没有任何结算 / 胜负画面，账本一直空着。
6. 被队友扔进门里不算；人落地后走出去、再自己走进来，才重新开始数那 1 秒。
7. 站在门洞里 / 退回门内：读条不推进（只在门外侧推）。
8. 解锁后宿管按 E 关不上门。
9. 自测要能变红：`钥匙锁口自测.gd` ⑨ 组（L140-153）补「没插满就推开门 → 不算」和「第二个人也能赢、同一个人不重复记」；原来偷看 `HUD/提示` 的断言改成看 `Match.escaped`。反向验证：把 `出口.gd` 临时连回 `door_finished`，这条必须失败。

## 八、容易卡住的地方（先说，省得明天以为在摸鱼）

1. **声音事件刷屏**：脚步/落地每帧 emit 会瞬间淹没日志和 AI 判断。第一天不接脚步；接了就必须节流。
