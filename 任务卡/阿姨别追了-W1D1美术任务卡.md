# 阿姨别追了 · 美术任务卡 01：风格样张

（这张卡是给美术看的：照它画完，把成品发给项目负责人）

> 一句话：画 **1 张「夜间宿舍楼道」的 2D 像素画**。这张画验收通过后，它就是全游戏的**风格锚点**——以后所有素材（角色、地砖、道具、UI）都对着它画，保证看起来像「同一个世界」。
> 附件：`色板_24色草案_2026-10-29.png`（随卡一起发）。
> 交期：尽快，最好本周内；不用一次完美，先交草稿也行（流程见 §五）。

**这是什么游戏**（画之前心里有个数）：4 个大学生趁夜里熄灯，在宿舍楼摸黑搬钥匙、合电闸，想办法躲过查夜的宿管阿姨。横版像素画面，**核心卖点是「手电光锥之内看得见、之外全黑」**——压迫感来自看不见，不靠血浆和恐怖。整体是轻松喜剧向（12+）。

---

## 一、这次就交一张

| 项    | 要求                                                                        |
| ---- | ------------------------------------------------------------------------- |
| 内容   | 夜间宿舍楼走廊，横版**侧视**（像老式横版过关游戏那样从侧面看，**不要斜角透视**）                              |
| 画面尺寸 | 640×360 起稿；想画细一点就按 2 倍画 **1280×720** 导出（我这边会整数倍缩回 640×360，所以千万不要 1.5 倍这类） |
| 交付格式 | PNG；文件名直接用中文起清楚：`风格样张_夜间宿舍楼道_昵称_日期.png`                                   |
| 源文件  | PSD / Aseprite 自己留一份别删（后面细化、切帧要用）                                         |

## 二、画里必须有的四样

1. **夜色里的走廊**
2. **一名学生像素小人**：手持手电、面朝右；**头身比 1:1**（头和身体一样高，大头造型，这是本项目的辨识度）
*楼道该有的东西**：水磨石地砖、斑驳墙面（可以有小块剥落墙皮）、墙上贴的小广告（红/白小色块示意即可）、深色宿舍门

## 三、硬规格（别自创）

| 项    | 规定                                                                              |
| ---- | ------------------------------------------------------------------------------- |
| 风格   | 2D **严格像素画**：粗颗粒像素点、大面积纯色块、硬边缘                                                  |
| 色数   | 全图 **≤ 24 色**（用附件色板）；单个角色 8~10 色                                                |
| 描边   | 1 px 深色描边，颜色随环境光偏移（**不要用纯黑**）                                                   |
| 渐变   | 禁止渐变、禁止半透明过渡；明暗用 3~4 档纯色的明度差表现                                                  |
| 光照   | 学生手电约 6 米长、25° 锥；全楼是「微光可见」（走路不撞墙），光锥外看不清细节                                      |
| 主色   | 夜蓝 `#1B2440`（夜色）/ 路灯黄 `#F2C777`（光）/ 校服白 `#E8EAF0` / 警示红 `#D9534F`               |
| 角色比例 | 学生头身比 **1:1**（头 1 身 1）；画面里学生高约 **44 px**（640×360 基准下；最终素材尺寸还没定稿，这张按 44 px 高画就行） |
| 图块网格 | 16×16 px 一格（地砖、墙、门都贴着网格对齐）                                                      |

## 四、明确不要的

- **不要把整张画照亮**光的整体氛围是黑的
- 不要写实、不要 3D 感、不要斜透视、不要渐变和半透明过渡
- 不要超过 24 色；
- 画面里不要出现文字、水印、签名（墙上小广告也只画色块示意，不要真写字）
- 不要做成恐怖血腥风——这是轻松喜剧向的游戏，吓人的点只有「看不见」

## 五、怎么交 & 怎么算过

流程（不用一次完美）：

1. 先交一张**草稿级**：色块 + 大形 + 明暗关系（地砖纹理、小广告细节都不用抠）→ 项目负责人看方向
2. 方向 OK 再细化出正式样张；最多来回 2~3 次
3. 验收通过：这张图就封为「风格锚点 v1」，之后的活都对着它画

验收清单（画完自己先打一遍勾）：

- [ ] 横版侧视，没有斜角透视
- [ ] 光锥内亮、光锥外黑，明暗差一眼能看出来
- [ ] 缩到 640×360 后轮廓还清楚、不糊
- [ ] 全图颜色 ≤ 24 个（对着色板数一遍）
- [ ] 学生是 1:1 头身的大头小人
- [ ] 描边是 1 px 深蓝灰，不是纯黑
- [ ] 图里没有文字 / 水印
- [ ] PNG 命名按 §一 的格式

## 六、可能想问的

**Q：为什么先只画一张？**
A：这张是全项目的「标准像」。后面画地砖、画角色、画 UI，都要能看起来像同一张画里出来的；标准定歪了，后面全白画。

**Q：色板的 24 个颜色必须全用上吗？**
A：不用全用，但**不许超出**。主角是夜色的 4 个深蓝和光的 4 个暖黄。

**Q：手电往哪照？学生什么姿势？**
A：横版侧视下只看侧影；光锥朝画面右侧展开（角色左右镜像复用，这一张画朝右就行）。姿势站着走都行，能看出「拿着手电在照」即可。

**Q：要画宿管吗？**
A：这张不用。宿管是另一套体型（头身比约 1:2、更大更魁梧），等角色阶段再派卡。

**Q：有疑问怎么办？**
A：直接问项目负责人（转发这张卡的人），别自己猜。
